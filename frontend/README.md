# Scrap Link — Phase 1 Frontend

Complete browser UI prototype for the Scrap Link application.

Run:
1. Extract this folder.
2. Open index.html in Chrome/Edge.
3. Use Generator or Collector demo login.
4. Test Dashboard, Waste Classification, Book Pickup, Price Estimator and Pickups.

Phase 1 uses browser localStorage only. It is intentionally not connected to the Spring Boot API yet.

Phase 2 will connect these screens to the existing Spring Boot + Supabase backend.
